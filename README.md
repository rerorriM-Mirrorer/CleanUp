# CleanUp

Windower 4 inventory home-and-override addon, in development.

**Source status:** This `main` branch is reserved for live-verified releases. No CleanUp build has yet been verified in FFXI. The current experimental Beta 1.1 is maintained on the [`dev` branch](https://github.com/rerorriM-Mirrorer/CleanUp/tree/dev).

Before enabling automatic cleanup, read the beta README and testing notes. In particular, disable competing automatic item movers and preview proposed transfers first.

Development practices are recorded in `WORKFLOW.md` and testing history in `TESTING.md`.
